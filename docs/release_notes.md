# リリースノート

## v1.1.1（2026-10-08）

### 修正
- **全画面表示中に自動スクロールしても続きが読み込まれない問題**（F-66）。原因は X 側で、ページ内の何かが全画面になっている間はタイムラインの描画更新と読み込みを止めること。対策として、全画面にしているのが当拡張機能のウィンドウであるときだけ、X からは「全画面ではない」と見えるようにした（`src/lib/fullscreen-shim`）。X 自身の動画の全画面には影響しない。実機で、全画面中に 20 件 → 41 件の読み込みを確認。

### 配布物
- `.output/x-auto-playlist-1.1.1-chrome.zip`

## v1.1.0（2026-10-08）

ホストが数日使った上での改善要望（`requirements.md` §8A）をすべて反映。実機（ログイン済みテストアカウント）で監査済み。

### 追加・変更
- **英語対応**：設定「言語」（自動／日本語／English）。UI の全文言、トースト、右クリックメニューが切り替わる（146 キー）。
- **個人アカウントのページでも自動収集**：ポスト（`/<user>`）、返信（`/with_replies`）、リポスト（`/reposts`）の 3 タブ。複数動画の投稿がメディアタブに出ない問題の回避策。
- **自動スクロールを高速化**：速さを「ゆっくり／普通／速い」の 3 段階に（既定は普通）。残り 5 件以下で発火、応答を待たずに間隔ごとに再スクロール、動画の残り 15 秒未満で残り 2 件以下なら即スクロール。
- **サムネイル左下に動画の長さ**を表示。
- **一覧の本文**は固定文字数ではなく、行の幅いっぱいに表示して末尾を「…」で省略（パネル幅に追従）。
- **全画面のメディア情報**：いいね／リポストのボタンを「全文／閉じる」の左に固定、本文を背景の幅いっぱいで折り返し（原文の改行は保持）、投稿者をクリックするとそのアカウントへ同じタブで移動。

### 配布物
- `.output/x-auto-playlist-1.1.0-chrome.zip`

## v1.0.0（2026-10-08）

最初の区切り。要件文書（`requirements.md`）の必須・推奨項目をすべて実装し、模擬環境とログイン済みの実タイムラインで監査済み（`final_check.md`）。

### 主な内容
- 自動／手動プレイリスト、右クリック追加、重複除外、ページ移動時の作り直し
- 分割ビューのサイドパネル（境目ドラッグ、幅の記憶、全画面中も表示）
- 浮かぶ再生ウィンドウ：再生操作一式、シークバー、VLC 風音量、速度、画質（自動＋各解像度）、PiP、全画面、メディア情報と全文シート、いいね／リポスト、パネル切替
- 先読み（次の 1 件）、画像／GIF の表示時間、X 側動画の停止、読み込み制限の検知
- 設定画面（15 項目＋投稿操作）、ライト／ダーク／システム、ショートカット
- 独自デザイン（配色・アイコン・拡張機能アイコン）、控えめなモーション、並べ替えのゴースト表示

### 見送り・既知の制限
- ブックマーク操作（X の署名ヘッダ要求のため）
- HLS のみの動画の再生
- 複数タブ同時利用
