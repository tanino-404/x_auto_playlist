# リリースノート

## v1.0.0（2026-10-08）

最初の区切り。要件文書（`requirements.md`）の必須・推奨項目をすべて実装し、模擬環境とログイン済みの実タイムラインで監査済み（`final_check.md`）。

### 主な内容
- 自動／手動プレイリスト、右クリック追加、重複除外、ページ移動時の作り直し
- 分割ビューのサイドパネル（境目ドラッグ、幅の記憶、全画面中も表示）
- 浮かぶ再生ウィンドウ：再生操作一式、シークバー、VLC 風音量、速度、画質（自動＋各解像度）、PiP、全画面、メディア情報と全文シート、いいね／リポスト、パネル切替
- 先読み（次の 1 件）、画像／GIF の表示時間、X 側動画の停止、読み込み制限の検知
- 設定画面（15 項目＋投稿操作）、ライト／ダーク／システム、ショートカット
- 独自デザイン（配色・アイコン・拡張機能アイコン）、控えめなモーション、並べ替えのゴースト表示

### 見送り・既知の制限
- ブックマーク操作（X の署名ヘッダ要求のため）
- HLS のみの動画の再生
- 複数タブ同時利用

### 配布物
- `npm run build` → `.output/chrome-mv3`
- `npm run zip` → `.output/x-auto-playlist-1.0.0-chrome.zip`
