## 2. 非機能・リスク
- N-04：構造変化の検知 → 模擬で 3 回連続の解釈失敗でバナー表示、正常応答で解除。
- 読み込み制限（429）→ 待機バナーとスクロール停止を確認。
- 規約リスク：投稿操作で実際に X の自動操作判定（226）が出た。**個人利用でも、短時間に操作を繰り返さないこと**。

## 3. 既知の制限
1. ブックマークは使えない（X の署名ヘッダ要求）。
2. リポスト／いいねは X の判定次第で拒否されることがある（トーストで案内）。
3. 直接再生できる形式が無い動画（HLS のみ）は「再生不可」表示（Chrome 142 以降のネイティブ HLS 対応を待って再検討）。
4. 自動画質は小窓の幅に合わせるため既定幅では低め。メニューで明示指定すれば持続する。
5. X 未ログイン時は収集されない。

## 4. 使い方（ホスト向け）
1. `npm run build` → `.output/chrome-mv3` を Chrome の拡張機能ページ（デベロッパーモード）で「パッケージ化されていない拡張機能を読み込む」。
2. x.com を開き、ツールバーのアイコンをクリック。右に分割ビューでパネルが出る。
3. ホーム／履歴（ブックマーク・いいね）を開くと自動で一覧に積まれる。再生ボタンかダブルクリックで再生。
4. 設定は歯車。ショートカット：Space、←→、Shift+←→、↑↓、F、M、L、S、P。
